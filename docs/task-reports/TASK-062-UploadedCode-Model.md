# TASK-062: UploadedCode SQLAlchemy 모델 생성

**완료일**: 2025-01-24
**관련 파일**: `backend/src/models/uploaded_code.py`

## 무엇을 만들었나요?

사용자가 업로드한 코드의 메타데이터를 저장하는 데이터베이스 모델을 만들었습니다. 이 모델은 마치 도서관의 도서 카드처럼, 업로드된 코드 파일들의 정보를 한눈에 볼 수 있게 정리해주는 역할을 합니다.

## 왜 이렇게 만들었나요?

각 학습 태스크(Task)마다 하나의 코드 업로드가 있고, 이 업로드된 코드에 대한 요약 정보가 필요합니다. 예를 들어:
- 어떤 프로그래밍 언어로 작성되었는지
- 코드가 얼마나 복잡한지 (초급/중급/고급)
- 전체 코드 줄 수가 몇 줄인지
- 파일이 몇 개인지
- 용량이 얼마나 되는지 (최대 10MB 제한)

이 정보들을 별도 테이블에 저장함으로써, 나중에 AI가 학습 문서를 생성할 때 필요한 기초 데이터로 활용할 수 있습니다.

## 어떻게 작동하나요?

1. **Task와 1:1 관계**: 하나의 태스크에는 하나의 UploadedCode만 연결됩니다 (unique 제약조건)
2. **연쇄 삭제(CASCADE)**: 태스크가 삭제되면 관련 UploadedCode도 자동으로 삭제됩니다
3. **유효성 검증**: 복잡도 레벨은 'beginner', 'intermediate', 'advanced' 중 하나만 가능합니다
4. **용량 제한**: 최대 10MB (10,485,760 바이트)까지만 허용됩니다

## TDD 사이클

이 태스크는 모델 정의만 포함하므로, 모델이 올바르게 import되는지 확인하는 간단한 검증을 수행했습니다:
- **GREEN**: 모델 생성 후 Python import 테스트 통과
- **검증 결과**: `UploadedCode` 모델이 정상적으로 로드되고, 테이블명과 상수값이 올바르게 설정됨

## 관련 개념

- **SQLAlchemy ORM**: Python에서 데이터베이스를 객체처럼 다룰 수 있게 해주는 도구
- **UUID**: 전 세계적으로 고유한 식별자 (중복 걱정 없음)
- **Foreign Key**: 다른 테이블의 데이터를 참조하는 연결고리
