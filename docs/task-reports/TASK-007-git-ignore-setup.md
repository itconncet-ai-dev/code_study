# Task 007: Git Ignore 패턴 설정

**완료일**: 2025-01-17
**상태**: ✅ 완료

## 무엇을 만들었나요?

프로젝트에서 Git이 추적하지 않아야 할 파일들을 지정하는 `.gitignore` 파일을 만들었습니다.

집에서 이사할 때를 생각해보세요. 모든 물건을 이삿짐 트럭에 싣지는 않죠? 쓰레기, 냉장고 안의 음식, 일회용품 같은 건 그냥 버리거나 새로 사면 됩니다. `.gitignore`는 프로젝트에서 "이건 Git 트럭에 안 실어도 돼"라고 알려주는 목록입니다.

## 왜 이렇게 만들었나요?

Git에 모든 파일을 저장하면 여러 문제가 생깁니다:

1. **용량 문제**: `node_modules` 폴더는 수백 MB에 달할 수 있어요. 마치 이사할 때 마트 전체를 옮기려는 것과 같습니다. 대신 "장보기 목록"(package.json)만 가져가면 새 집에서 다시 살 수 있죠.

2. **보안 문제**: `.env` 파일에는 비밀번호나 API 키 같은 민감한 정보가 들어있어요. 이걸 Git에 올리면 일기장을 광장에 전시하는 것과 같습니다.

3. **충돌 방지**: 컴퓨터마다 자동으로 생성되는 파일들(`__pycache__`, `.venv`)이 있어요. 이런 파일은 사람마다 달라서 Git에 올리면 불필요한 충돌이 생깁니다.

## 어떻게 동작하나요?

`.gitignore` 파일에 패턴을 적으면 Git이 해당 파일들을 무시합니다:

- `node_modules/` - 프론트엔드 패키지 폴더 전체 무시
- `*.pyc` - 파이썬 컴파일 파일 무시
- `.env` - 환경설정 파일 무시
- `storage/uploads/` - 사용자가 업로드한 코드 파일 무시

## 수정된 파일

| 파일 | 변경 내용 |
|------|----------|
| `.gitignore` | 새로 생성 - Python, Node.js, IDE, OS 패턴 포함 |
| `.dockerignore` | 이미 존재함 - 확인 완료 |

## 관련 개념

- **Git**: 코드의 변경 이력을 관리하는 도구 (타임머신 같은 것)
- **가상환경 (venv)**: 프로젝트마다 별도의 파이썬 패키지를 설치할 수 있게 해주는 격리 공간
- **node_modules**: 프론트엔드 프로젝트의 외부 라이브러리가 저장되는 폴더

## 주의사항

- `.gitignore`에 추가하기 전에 이미 Git에 추가된 파일은 별도로 `git rm --cached` 명령으로 제거해야 합니다.
- `storage/` 폴더 자체는 유지하되 업로드된 파일만 무시하도록 `.gitkeep` 파일을 활용합니다.
