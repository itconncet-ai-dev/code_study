# Task 014: FastAPI 앱 초기화 및 CORS 미들웨어 설정

**완료일**: 2025-01-19
**파일**: `backend/src/main.py`

## 무엇을 만들었나요?

FastAPI 웹 서버의 "메인 진입점"을 만들었습니다. 마치 회사의 정문처럼, 모든 API 요청이 이 파일을 통해 들어오고 나갑니다.

## 왜 이렇게 만들었나요?

### CORS (Cross-Origin Resource Sharing)
웹 브라우저는 기본적으로 다른 도메인(예: localhost:5173)에서 우리 서버(localhost:8000)로 요청을 보내는 것을 막습니다. 이것은 보안 기능인데, CORS 설정을 통해 "이 도메인들은 괜찮아!"라고 허용해주는 것입니다. 마치 경비원이 신분증을 확인하고 출입을 허가하는 것과 같습니다.

### Request ID 미들웨어
모든 요청에 고유한 ID를 붙여줍니다. 마치 음식점에서 주문 번호를 받는 것처럼, 나중에 문제가 생겼을 때 "이 요청에서 문제가 발생했다"고 추적할 수 있게 해줍니다.

### Lifespan 이벤트
서버가 시작될 때와 종료될 때 특별한 작업을 할 수 있게 해줍니다. 예를 들어, 데이터베이스 연결을 열고 닫는 것이죠.

## 어떻게 동작하나요?

1. **설정 로드**: 환경 변수에서 설정값들을 읽어옵니다 (CORS_ORIGINS, APP_ENV 등)
2. **앱 생성**: FastAPI 앱을 만들고 설명, 버전 등 메타데이터를 설정합니다
3. **미들웨어 추가**: CORS와 Request ID 미들웨어를 순서대로 추가합니다
4. **엔드포인트 등록**: 건강 체크(`/health`)와 루트(`/`) 엔드포인트를 등록합니다
5. **라우터 준비**: 나중에 인증, 프로젝트 등의 API 라우터들이 추가될 자리를 만들어둡니다

## 수정된 파일

- **생성**: `backend/src/main.py` - FastAPI 앱 초기화 파일

## 관련 개념

- **미들웨어(Middleware)**: 요청과 응답 사이에서 중간 처리를 담당하는 코드. 마치 배달 중간에 거치는 물류센터와 같습니다.
- **CORS**: 브라우저 보안 정책. 다른 도메인에서 오는 요청을 제어합니다.
- **Lifespan**: 앱의 생명주기. 시작부터 종료까지의 흐름을 관리합니다.
- **환경 변수**: 코드 외부에서 설정값을 주입하는 방법. 개발/운영 환경을 쉽게 구분할 수 있습니다.

## 주의사항

- 운영 환경에서는 `CORS_ORIGINS`를 실제 프론트엔드 도메인으로 제한해야 합니다
- `DEBUG=false`로 설정하면 API 문서(/docs)가 비활성화됩니다
- `SECRET_KEY`는 반드시 안전한 랜덤 문자열로 교체해야 합니다
