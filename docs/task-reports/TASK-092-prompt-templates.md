# Task 092: 7장 학습 문서 생성을 위한 프롬프트 템플릿 구현

**작성일**: 2026-01-24
**상태**: 완료
**파일**: `backend/src/services/ai/prompts.py`

## 무엇을 만들었나요?

AI가 코드를 분석해서 초보자용 학습 문서를 만들 때 사용하는 "대화 지침서"를 만들었습니다. 마치 선생님에게 "이렇게 설명해주세요"라고 미리 알려주는 것과 같습니다.

## 왜 이렇게 만들었나요?

프로그래밍을 전혀 모르는 사람도 이해할 수 있는 설명서가 필요합니다. AI에게 그냥 "설명해줘"라고 하면 전문용어를 많이 쓰게 됩니다. 그래서 미리 규칙을 정해놓았습니다:

- "절대 전문용어만 쓰지 말고, 반드시 쉬운 말로 바꿔 설명해라"
- "모든 개념에 실생활 비유를 넣어라"
- "처음 프로그래밍을 배우는 사람이라고 생각하고 설명해라"

## 어떻게 작동하나요?

7개의 챕터 각각에 대해 AI에게 주는 지침을 만들었습니다:

1. **1장 - 이 코드가 뭘 하는지**: 한 문장으로 요약 (계산기, 주소록처럼 쉬운 비유로)
2. **2장 - 미리 알아야 할 것들**: 변수, 함수 같은 기본 개념 카드 5개 (각각 비유 포함)
3. **3장 - 코드 구조**: 순서도로 코드의 흐름을 보여줌
4. **4장 - 줄줄이 설명**: 모든 코드 줄을 하나씩 설명
5. **5장 - 실행 과정**: 컴퓨터가 코드를 실행하는 과정을 단계별로 보여줌
6. **6장 - 핵심 개념 정리**: 이 코드에서 배운 중요한 개념들
7. **7장 - 흔한 실수들**: 초보자가 자주 하는 실수 3-5개와 해결법

## 어떻게 테스트했나요?

**TDD 방식**으로 진행했습니다:

1. **RED 단계**: 먼저 prompts.py 파일이 없는 상태에서 import를 시도 → 실패 확인
2. **GREEN 단계**: prompts.py 파일을 만들고 모든 프롬프트 템플릿과 헬퍼 함수 구현
3. **검증**: Python import 테스트로 모듈이 제대로 로드되는지 확인

```python
from src.services.ai.prompts import DocumentPrompts, get_document_generation_prompt
# Import successful
```
