## 작업 개요
업로드된 코드 파일을 파일시스템에 저장하고 관리하는 FileStorageService를 구현했습니다.

## 구현 내용

### 파일 경로: `backend/src/services/code_analysis/file_storage.py`

### 주요 기능
1. **파일 저장 경로 생성**
   - 디렉토리 구조: `storage/uploads/{user_id}/{task_id}/{uuid}.{ext}`
   - UUID를 사용한 고유 파일명 생성
   - 원본 파일 확장자 보존

2. **비동기 파일 작업**
   - `aiofiles` 라이브러리를 사용한 비동기 I/O
   - 파일 저장, 읽기, 삭제 기능
   - 디렉토리 자동 생성

3. **구현된 메서드**
   - `generate_storage_path()`: 저장 경로 생성
   - `save_file()`: 파일 저장
   - `read_file()`: 파일 읽기
   - `delete_file()`: 파일 삭제
   - `delete_task_files()`: 태스크 전체 파일 삭제
   - `file_exists()`: 파일 존재 확인

## 기술적 결정사항

### 저장 구조 선택
- 사용자별, 태스크별 디렉토리 분리
- 파일 충돌 방지를 위한 UUID 사용
- 확장자 보존으로 파일 타입 식별 용이

### 비동기 I/O 사용
- FastAPI의 비동기 특성에 맞춤
- 파일 작업 시 블로킹 방지
- 높은 동시성 처리 능력
