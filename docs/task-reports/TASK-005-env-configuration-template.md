# Task 005: 환경 설정 템플릿 생성

**완료일**: 2025-01-16
**파일**: `.env.example`

## 무엇을 만들었나요?

프로젝트의 환경 변수 설정을 위한 템플릿 파일(`.env.example`)을 만들었습니다. 이 파일은 마치 새 집에 이사 왔을 때 받는 "입주 안내서"와 같습니다 - 가스, 전기, 인터넷 등 각종 서비스를 연결하는 데 필요한 정보들이 정리되어 있죠.

## 왜 이렇게 만들었나요?

실제 비밀번호나 API 키를 코드에 직접 넣으면 위험합니다. 마치 집 열쇠를 문 앞 화분 아래 두는 것처럼요. 대신 `.env` 파일에 비밀 정보를 저장하고, `.env.example`은 "여기에 이런 정보가 필요해요"라고 알려주는 가이드 역할을 합니다.

## 어떤 설정들이 포함되나요?

1. **데이터베이스 (PostgreSQL)**: 사용자 정보, 프로젝트, 학습 문서를 저장하는 창고의 주소와 비밀번호
2. **Redis**: 백그라운드 작업 관리를 위한 메시지 전달 시스템 설정
3. **JWT 인증**: 로그인 상태를 유지하기 위한 보안 토큰 설정
4. **Google Gemini AI**: 코드 설명 문서를 생성하는 AI 서비스 연결 키
5. **Celery**: 시간이 오래 걸리는 작업을 백그라운드에서 처리하는 시스템 설정
6. **파일 저장소**: 업로드된 코드 파일을 보관할 위치
7. **CORS**: 프론트엔드와 백엔드가 안전하게 통신하기 위한 허용 목록

## 어떻게 사용하나요?

```bash
# 1. 템플릿 파일을 복사해서 실제 설정 파일 만들기
cp .env.example .env

# 2. .env 파일을 열어서 실제 값 입력하기
# - 데이터베이스 비밀번호
# - Gemini API 키 (https://aistudio.google.com/app/apikey 에서 발급)
# - 보안을 위한 시크릿 키 (openssl rand -hex 32 로 생성)
```

## 주의사항

- **절대로 `.env` 파일을 Git에 올리면 안 됩니다!** (`.gitignore`에 추가 필수)
- 프로덕션(실제 서비스) 환경에서는 반드시 모든 시크릿 키를 새로 생성해야 합니다
- `APP_ENV=production`으로 설정하면 디버그 정보가 숨겨집니다
