# TASK-079: TaskCard 컴포넌트

**작업 유형**: 프론트엔드 UI 컴포넌트
**파일 위치**: `frontend/src/components/task/TaskCard.tsx`
**완료일**: 2025-01-24

## 무엇을 만들었나요?

프로젝트 상세 페이지에서 각 작업을 카드 형태로 보여주는 컴포넌트입니다. 작업 번호, 제목, 업로드 방식, 생성일을 한눈에 볼 수 있고, 클릭하면 작업 상세 페이지로 이동합니다.

## 왜 이렇게 만들었나요?

작업 목록을 보여줄 때 각 작업의 핵심 정보를 압축해서 보여줘야 합니다. 카드 UI는 정보를 구조화하기 좋고, 클릭 가능한 영역이 넓어 사용하기 편합니다.

## 어떻게 동작하나요?

1. **작업 번호 배지**: "작업 #1" 형태로 순서 표시
2. **업로드 방식 아이콘**: 파일/폴더/붙여넣기에 따라 다른 아이콘
3. **제목과 설명**: 작업의 핵심 내용 표시
4. **날짜 정보**: 한국어 형식으로 생성일 표시 ("2025년 1월 24일")

## 주요 기능

```tsx
const UPLOAD_METHOD_LABELS = {
  file: '파일',
  folder: '폴더',
  paste: '붙여넣기',
}

const UPLOAD_METHOD_ICONS = {
  file: FileText,    // lucide-react 아이콘
  folder: Folder,
  paste: Code,
}
```

- `Link` 컴포넌트로 전체 카드가 클릭 가능
- `hover:shadow-md`로 마우스 오버 시 시각적 피드백
- 한국어 날짜 포맷팅 (`toLocaleDateString('ko-KR')`)
