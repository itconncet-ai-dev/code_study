# TASK-083: TaskDetail 페이지 스켈레톤

**작업 유형**: 프론트엔드 페이지
**파일 위치**: `frontend/src/pages/TaskDetail.tsx`
**완료일**: 2025-01-24

## 무엇을 만들었나요?

작업 상세 페이지의 기본 구조(스켈레톤)입니다. 작업 정보와 함께 문서, 실습, Q&A 세 개의 탭을 포함합니다. 각 탭의 실제 기능은 다음 Phase에서 구현됩니다.

## 왜 이렇게 만들었나요?

작업 상세 페이지는 플랫폼의 핵심입니다. 사용자가 코드를 업로드하면 이 페이지에서 학습 문서를 읽고, 실습을 하고, AI에게 질문합니다. 먼저 기본 레이아웃과 네비게이션을 만들고, 실제 기능은 단계별로 추가합니다.

## 어떻게 동작하나요?

1. **작업 정보 헤더**: 작업 번호, 제목, 설명 표시
2. **탭 네비게이션**: 문서/실습/Q&A 세 개의 탭
3. **탭 콘텐츠**: 선택된 탭에 따라 다른 내용 표시
4. **뒤로가기**: 프로젝트 상세 페이지로 돌아가기

## 주요 기능

```tsx
type TabType = 'document' | 'practice' | 'qa'

const [activeTab, setActiveTab] = useState<TabType>('document')

// 탭 네비게이션
<button onClick={() => setActiveTab('document')}>문서</button>
<button onClick={() => setActiveTab('practice')}>실습</button>
<button onClick={() => setActiveTab('qa')}>Q&A</button>
```

- URL 파라미터에서 taskId 추출
- TanStack Query로 작업 데이터 조회
- 로딩/에러 상태 처리

## 탭별 예정 기능

| 탭 | Phase | 내용 |
|-----|-------|------|
| 문서 | 6 | 7개 챕터 학습 문서 표시 |
| 실습 | 7 | 5개 연습 문제 + 코드 에디터 |
| Q&A | 8 | AI 채팅 인터페이스 |

## 수정한 파일

- `frontend/src/pages/TaskDetail.tsx` (업데이트)

## 관련 개념

- **탭 네비게이션**: 같은 페이지 내에서 콘텐츠 전환
- **스켈레톤 UI**: 기본 구조만 먼저 만들고 기능을 점진적으로 추가
- **ARIA 속성**: `role="tab"`, `aria-selected`로 접근성 향상

## UI 구조

```
작업 상세 페이지
├── 뒤로가기 링크 (← 프로젝트로 돌아가기)
├── 작업 헤더 카드
│   ├── 작업 번호 (#1, #2, ...)
│   ├── 제목
│   └── 설명 (선택적)
├── 탭 네비게이션
│   ├── 문서 (기본 선택)
│   ├── 실습
│   └── Q&A
└── 탭 콘텐츠 영역
    └── 현재는 플레이스홀더 메시지
```

## 주의사항

- 각 탭의 상태는 현재 로컬 state로 관리 (URL에 반영하지 않음)
- 에러 상태에서 프로젝트로 돌아가기 링크 표시
