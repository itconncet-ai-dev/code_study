# TASK-076: FileUpload 컴포넌트

**작업 유형**: 프론트엔드 UI 컴포넌트
**파일 위치**: `frontend/src/components/upload/FileUpload.tsx`
**완료일**: 2025-01-24

## 무엇을 만들었나요?

파일을 업로드하는 드래그 앤 드롭 컴포넌트입니다. 마치 이메일에 첨부파일을 추가할 때처럼, 파일을 끌어다 놓거나 클릭해서 선택할 수 있습니다.

## 왜 이렇게 만들었나요?

사용자가 코드 파일을 쉽게 업로드할 수 있도록 직관적인 인터페이스가 필요했습니다. 드래그 앤 드롭은 가장 익숙한 파일 업로드 방식이라 이를 기본으로 선택했습니다.

## 어떻게 동작하나요?

1. **드래그 앤 드롭 영역**: 파일을 끌어다 놓으면 파란색으로 강조되어 "여기에 놓으세요"라는 시각적 피드백을 줍니다
2. **파일 검증**: 지원하는 확장자(.py, .js, .ts 등)와 10MB 이하인지 자동 확인
3. **선택된 파일 목록**: 각 파일의 이름, 크기, 확장자를 보여주고 개별 삭제 가능
4. **에러 표시**: 지원하지 않는 파일이면 빨간색 경고 메시지 표시

## 주요 기능

```tsx
// 지원 확장자
const SUPPORTED_EXTENSIONS = ['.py', '.js', '.ts', '.jsx', '.tsx', '.html', '.css', ...]

// 최대 파일 크기 (10MB)
const MAX_FILE_SIZE = 10 * 1024 * 1024
```

- `onFilesChange` 콜백으로 선택된 파일 배열 전달
- 드래그 이벤트 처리 (dragEnter, dragLeave, dragOver, drop)
- 파일 크기를 KB/MB 단위로 자동 변환 표시

## 수정한 파일

## 관련 개념

- **Drag and Drop API**: 브라우저가 제공하는 끌어다 놓기 기능
- **FormData**: 파일 업로드 시 서버로 전송하는 데이터 형식
- **MIME 타입**: 파일 종류를 구분하는 표준 방식

## 주의사항

- 폴더 업로드는 별도 컴포넌트(FolderUpload)에서 처리
- multiple 속성으로 여러 파일 동시 선택 가능/불가능 제어
